# Open Web Application Security Project (OWASP)

Focada em melhorar a segurança de softwares. 
Ela oferece uma vasta gama de recursos e ferramentas sem custo, 
destinados a auxiliar organizações no desenvolvimento e manutenção de aplicativos web seguros.

## Controle de Acesso Quebrado
Permissao a usuários não autorizados acessar recursos ou funcionalidades que deveriam 
estar restritos

## INJEÇÂO
é um tipo comum de falha de segurança. Ela ocorre quando dados não confiáveis são tratados como código 
ou comandos pelo sistema, permitindo que um atacante insira código malicioso para ser execultado.

### Tipos
  * **SQL Injection**;
  * **Command Injection;**
  * **Cross-Site Scripting**


## Design Inseguro
Falha no projeto de um sistema. que cria uma vunerabilidade significativa de segurança.
Isso ocorre quando o design da aplicação não leva em conta práticas de segurança adequadas desde o início,


## Configiuração incorreta de segurança
Aplicação ou componente que deixa brechas de seguranca abertas.
Ocorrem quando administradores nao configuram corretamente as defesas.


## Componentes desatualizados
Bibliotecas frameworks ou coutros desatualizados. isso pode criar pontos de entradas para ataques
